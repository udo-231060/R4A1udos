# 研究計画

## 研究テーマ
学校全体で利用できる、匿名性を段階的に選べるメディア対応チャットシステムの設計・開発・評価。

## 目的
全体チャット、個人チャット、画像・ショート動画による情報共有を支援する。匿名レベルが発言のしやすさ、安心感、会話の継続性に与える影響を評価する。

## 要求された機能
- 全体チャット
- 1対1の個人チャット
- 画像投稿・表示
- ショート動画投稿・再生
- 利用者ごとの匿名レベル0〜3の設定

## 匿名レベルの初期案
| レベル | 表示 | 継続性 |
| --- | --- | --- |
| 0 | 登録名 | 名前が見える |
| 1 | ニックネーム | 同じ名前で活動する |
| 2 | 会話ごとに固定の仮名 | 同じ会話内だけ追いやすい |
| 3 | 投稿ごとの匿名名 | 投稿者同士の対応を表示しない |

個人チャットは会話の構造から同じ相手と分かるため、レベル3でも相手の継続性を隠せるわけではない。匿名性は一般利用者に対する表示の設計であり、運営者に対する完全匿名や通信の匿名化を意味しない。

## 開発段階
1. 限定公開の研究試作：保存・送受信・メディア・匿名設定を実装。
2. 学校の参加者確認：学校メールまたは学校指定の認証、教職員・管理者の役割を決定。
3. 学内の少人数で検証：通報対応、ブロック、負荷、使いやすさを評価。
4. 学校の運用方針を確認したうえで対象者を広げる。

## 評価方法
- 機能：送信、再読み込み後の保存、画像・動画再生、匿名設定の反映。
- 権限：第三者が個人チャットや添付ファイルを取得できないこと。
- 匿名性：他人の投稿に内部ID・登録名・メールが含まれないこと（選択した公開名を除く）。
- 性能：同時利用者数と応答時間を測定し、目標値は学校の想定規模に合わせて設定。
- 使用感：匿名レベル別の発言しやすさ・安心感・分かりやすさをアンケートで比較。

## 未決定
