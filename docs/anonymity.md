# 匿名性の仕様

## 一般利用者への表示
0は利用者が入力した登録名（本人確認済みの実名とは限らない）、1はニックネーム、2は会話単位のランダムな固定仮名、3は投稿単位の匿名名。

- 初期値は1。登録名やメールを自動公開しない。
- 設定はサーバー側に保存し、0・1・2・3以外は受け付けない。
- 投稿時の表示名を保存し、設定変更で過去の表示名を再計算しない。
- 0で投稿するには登録名の入力が必要。
- 本文・画像・音声・動画に含まれる情報まで匿名化する機能ではない。
- レベルを切り替えることで、前後の文章や時刻から推測される場合がある。
- 1対1の会話では相手の連続性が残る。匿名の相手を新たに検索・特定する機能は提供しない。

## 内部の識別
ログイン用の識別子はサーバー内で管理する。他の利用者への投稿レスポンスには含めない。添付は投稿と同じ閲覧権限を確認する。通報記録は内部の投稿に紐付ける。

## 学校での運用前に決めること
学校の本人確認、管理者による照会権限と記録、通報対応・停止手順、保存・削除期間、画像等の位置情報やメタデータ除去、参加者への説明。
