# 卒業研究 — R4A1udos

研究の計画、プログラム、実験結果、論文をまとめるリポジトリです。

## 最初にすること

1. [研究計画](docs/research-plan.md)に、研究テーマ・目的・今後の予定を書く。
2. 既存のプログラムがあれば `src/` に入れる。
3. 作業した日は[研究ノートのひな形](notes/template.md)をコピーし、`notes/YYYY-MM-DD.md` として記録する。
4. 次にやることをGitHubの **Issues** に登録する。「文献を3本読む」など、完了が判断できる大きさに分ける。

## フォルダーの使い分け

| 場所 | 入れるもの |
| --- | --- |
| [docs/](docs/) | 研究計画、参考文献、実験手順などの説明 |
| [notes/](notes/) | 日々の研究記録、先生との相談メモ |
| [src/](src/) | プログラム |
| [data/](data/) | 手元で使うデータ。初期設定ではデータ本体をGitHubへ送信しない |
| [results/](results/) | 共有する図・表・評価結果 |
| [thesis/](thesis/) | 卒業論文・発表資料の原稿 |

## 普段の進め方

1. 作業前に最新の変更を取り込む。
2. プログラムや資料を編集する。
3. 研究ノートに「やったこと・結果・次にやること」を書く。
4. 保存する変更を確認して、内容が分かるメッセージで記録する。
5. GitHubへ送信する。

ターミナルを使う場合は、このフォルダーで次の操作をします。

```sh
# 作業前：GitHubの変更を取り込む
git pull --ff-only

# 作業後：変更を確認する
git status
git diff

# 保存したいファイルを指定する（例）
git add README.md docs/research-plan.md
git commit -m "研究計画を更新"
git push
```

新しく作ったファイルや画像の内容は、ファイル自体を開いて確認します。

## 研究を再現できるようにする

- プログラムの実行方法と使用したソフトのバージョンを `src/README.md` に書く。
- データの入手元・取得日・加工方法を `data/README.md` に書く。
- 実験の条件と結果を研究ノートに残す。結果には対応するコードのコミットも記録する。
- 参考文献は [docs/references.md](docs/references.md) にまとめる。

## 共有するファイルについて

パスワード、APIキー、個人情報、配布できない研究データは追加しないでください。データ本体や一時ファイルは `.gitignore` で除外しています。公開やライセンスの設定は、研究室の方針を確認してから決めます。
