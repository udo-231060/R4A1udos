# Campus Chat — R4A1udos

学校全体で使えるチャットと、利用者が選べる匿名性を研究する卒業研究です。

## 試作版

全体チャット、個人チャット、画像・ショート動画の投稿、匿名レベル0〜3の設定を実装しています。学校の在籍確認を組み込む前の研究試作です。

- [試作版を開く](https://r4a1udos-campus-chat.uddipenshisu.chatgpt.site)（所有者限定で公開済み）
- [プログラムと起動方法](src/campus-chat/README.md)
- [研究計画](docs/research-plan.md)
- [匿名性の仕様](docs/anonymity.md)

## 匿名レベル

| レベル | 表示名 |
| --- | --- |
| 0 | 登録名 |
| 1 | ニックネーム |
| 2 | 会話ごとの仮名 |
| 3 | 投稿ごとの匿名名 |

設定は新しい投稿から適用されます。運営者に対する完全匿名ではありません。個人チャットでは、同じ会話相手であることは分かります。

## 研究の進め方

[研究ノート](notes/template.md)を日付のファイル名でコピーし、実装・評価の結果を残します。次の作業はGitHubのIssuesで管理できます。

## 次の課題

学校の認証方式、管理者の役割、通報への対応画面、ブロック・利用停止、保存期間、動画の変換処理、負荷試験を検討します。
